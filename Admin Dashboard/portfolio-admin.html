Certification Images

Upload up to 10 certificate images. They appear as an auto-rotating slider (changes every 6 seconds) in the "Certifications" section on index.html. Visitors can click any image to view it enlarged. Drag any slot's image to reorder it.

Recommended: clear, well-lit photos or scans of your certificates (PNG or JPG). At least 5 images recommended for a smooth slider experience.

How to push your edits to GitHub Pages:
1. Fill in your sections and click Save All — data is stored in localStorage.
2. Choose which file you want to update below, then click Generate Script.
3. Paste the script just before </body> in the corresponding file on GitHub.
4. Commit & push — GitHub Pages rebuilds automatically.

Note: The index.html script injects the portfolio grid + carousel + fun facts.
The projects.html script injects the accordion panels with full project details.
